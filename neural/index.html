What is actually neural?

PC-NSF-HiFiGAN generates a new waveform from mel features and target pitch. Pitch tracking, harmony intervals, reference cancellation, and safety are DSP or rules.

The streaming adapter uses bounded overlapping windows. It does not wait for a finished song, but it is not a natively causal neural model.

Read the comparison correctly

Signalsmith is the exact vendored synthesis core at 60 ms. Chrome’s device AEC, gate, and notch graph are absent from this reproducible simulation. This is not a full baseline room comparison.

Clean-singer error is measured before synthesis. Muting is reported separately and never counted as successful separation.
